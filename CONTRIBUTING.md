# Contributing

Thanks for your interest. This is a research-only, hypothesis-generating project.

- **Issues:** report bugs, data errors, or wrong citations via GitHub Issues. Include the script, input file and exact error.
- **Pull requests:** keep them small and focused. One change per PR; explain why.
- **Reproducibility:** pin any new dependency in `requirements.txt`; do not commit files over 50 MB.
- **Never commit** `.env`, API keys, raw GSE163973 files, or AlphaFold Server outputs (see `LICENSE-DATA`).
- **Scientific claims:** results are predictions. Do not add clinical or "cure" language; cite a source for every factual claim.
- By contributing you agree your code is released under the MIT licence and author-written text and non-AlphaGenome/AlphaFold data under CC BY 4.0 (AlphaGenome- and AlphaFold-derived files stay under `TERMS_NOTICE.md`).
